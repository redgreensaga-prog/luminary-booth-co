STACK DECISION: Next.js 14 (App Router) + Tailwind CSS + Framer Motion

JUSTIFICATION: Next.js 14 provides optimal SEO capability with App Router metadata API and JSON-LD support, perfect Vercel deployment compatibility, and TypeScript-first development. Framer Motion offers spring physics and scroll-triggered animations without layout thrashing. Tailwind CSS enables rapid, consistent UI development with design token integration.

TRADE-OFFS ACCEPTED: Slightly larger initial bundle than Astro or SvelteKit, but worth it for superior developer experience, React ecosystem maturity, and client maintainability. We accept the React hydration overhead for superior interactive components and form handling.
